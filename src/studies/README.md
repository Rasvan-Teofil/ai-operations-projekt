# Neue Studien

Neue Untersuchungen künftig in einem Paket `<name>/` mit `__init__.py`, CLI und README ablegen. Gemeinsame Inferenz weiter aus den vorhandenen Laufzeitmodulen importieren; keine kopierte Modelllogik. Die bisherigen flachen Module bleiben als eingefrorener Bestand erhalten. Protokoll und Ergebnisse unter `reports/<name>/`, Rohdaten und Gewichte lokal unter `data/<name>/` und `models/<name>/`.
